# 🧩 教学助手对话智能体 — 编程环境模块（优化需求文档）

## 📌 项目背景
- **项目名称**：教学助手对话智能体（面向K12中小学生）
- **我的角色**：负责“编程环境”功能模块开发
- **目标**：为高年级学生提供在线编程实践环境，支持交互式编写、运行、调试代码，功能类似OJ平台

## 🎯 总体目标

## 1️⃣ 前端界面优化（UI/UX）

### 设计要求
- 整体风格**精美、清晰**，符合**企业级应用审美**
- 同时**偏卡通风格**，色彩活泼明亮，吸引K12年龄段学生
- **界面易上手**，操作路径直观，减少学习成本

### 功能丰富化
- 代码编辑器（支持语法高亮）
- 运行/调试/停止按钮
- 输出控制台（实时显示运行结果）
- 错误提示区（可视化展示，与代码行关联）
- 代码模板/示例库（一键加载）
- 字体大小调节 / 主题切换（亮色/暗色）
- 代码保存 / 历史记录查看

## 4️⃣ 技术实现与部署要求

### 当前技术栈
- 后端：FastAPI
- 队列：Redis
- 执行隔离：subprocess（暂不使用 Docker）

### 必须完成
- ✅ 项目能够在本地/服务器上**正常跑起来**
- ✅ 网页端功能完整可用，无崩溃或卡死

### 安全性要求（⚠️ 重要）
- 严格限制代码执行权限，防止：
  - 文件系统恶意操作（读写删除）
  - 系统命令注入
  - 资源耗尽（死循环、内存爆炸）
  - 网络请求滥用
- 考虑设置：
  - 执行超时机制
  - 资源配额限制（CPU/内存）
  - 禁用危险内置模块（如 `os`、`subprocess`、`socket` 等）
- 确保**主机电脑安全**，不因运行学生代码而受到损害

### 扩展性
- 代码结构需清晰，接口设计规范
- 后续能够顺利对接其他功能模块（如用户系统、课程体系、学习记录等）
